# WebCatalog

Este projeto consiste de um catálogo digital de promoções de produtos, contando com a funções de busca de itens e encomenda via Whatsapp.

Desenvolvido usando [Expo](https://expo.dev).

## Guia de Instalação

1. Rode o seguinte comando para instalar as dependências

   ```bash
   npm install
   ```

2. Rode o comando para iniciar o app

   ```bash
   npx expo start 
   ```
